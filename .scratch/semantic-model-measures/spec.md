# Semantic model measure layer: 38 base measures, raw additive columns hidden

> *This was generated by AI from a conversation and is the spec for ticket breakdown.*

## Problem Statement

`NYC_VehicleCrashes_Semantic` has **no measures**. They were all removed in the header/line remodel
(`.scratch/_Archive/header-line-remodel/`, D5), deliberately deferred until the model was clean. The
measure-readiness fixes (`.scratch/_Archive/measure-readiness-fixes/`) are now done in every stage:
calendar sorting, no blank member, cleansed Person Age and Vehicle Model Year.

Without measures, the model isn't usable as the portfolio deliverable:

- **Report authors drag raw columns** and get implicit aggregations. These can't be referenced by other
  DAX, don't appear in Excel PivotTables over the model, can be switched to Average or Count per visual,
  and stop working entirely once calculation groups set `discourageImplicitMeasures`.
- **The obvious calculations are wrong in subtle ways that only profiling reveals.** The 2026-10-12
  review of a first draft against Dev found six defects:
  - DAX treats `BLANK < 18` as TRUE, so the 1.21M unknown ages counted as children. The draft
    returned 5,682 child casualties for 2012 instead of 3,185.
  - `Dim Date` runs to 2030-12-31 but the data ends 2026-06-11. A naive Rolling 12M returned year-to-date
    for 2026, and a naive prior year compared half of 2026 with all of 2025, a false −57%.
  - A daily average divided by days with crashes, which inflates under a rare-factor filter.
  - Ejection Rate omitted "Partially Ejected" (13,513 people). Ejection Rate and Unlicensed Driver %
    divided by populations dominated by blank values: 2.9M person rows and 2.46M vehicles.
- **The columns and the measures would share names.** A measure can't share a name with a column in
  its own table, so `Persons Killed` can't be both.

## Solution

Add one governed layer of **38 explicit measures** (2 of them hidden helpers), each homed on the fact
table it counts. Every measure has a distinct business name, a format string, a display folder and a
`///` description that names its source:

- **Reported injury counts** are the crash-record figures on `Fact Crashes`.
- **Recorded injured persons** are the person-record figures on `Fact Crash Persons`.

The raw additive columns the measures replace are hidden, so measures are the only aggregate surface.
Authoring follows the local-TMDL workflow, proven in Dev and then promoted to Test and Prod through the
deployment pipeline. Only the semantic model is deployed; no Warehouse change is involved.

## Implementation Decisions

- **Measure home.** Each measure lives on the fact table whose rows it counts. There is no separate
  measures table. Cross-fact ratios live on the numerator's table.
- **Names.** Measure names are distinct from every column name. Summed casualty columns are prefixed
  `Total ` (for example `Total Persons Killed`). Person-level casualty counts say so in the name
  (`Injured Persons (Person-Level)`).
- **Hidden columns.** `isHidden` on:
  - `Fact Crashes`: Persons, Pedestrians, Cyclists and Motorists × Injured, Killed (8 columns).
  - `Fact Crash Persons`: Person Age.
  - `Fact Crash Vehicles`: Vehicle Occupants.

  These stay visible because they filter or map rather than aggregate: Latitude, Longitude, Is Injured,
  Is Killed.

  The SummarizeBy rules in `CLAUDE.md` are unchanged and still apply to the hidden columns.

  Hiding Person Age removes it as a visual axis. Age bands, if wanted later, need a visible band column
  or dimension; that's out of scope here.
- **Helpers.** `First Data Date` and `Last Data Date` are hidden measures. They are derived from
  `Fact Crashes`[date_key] with all filters removed, and anchor every calendar-sensitive measure,
  because `Dim Date` extends years beyond the data.
- **Format strings.** Counts use `#,0`, rates and percentages use `0.0%`, averages use `#,0.00`, and
  dates use `yyyy-mm-dd`. `Fatalities per 1,000 Crashes` uses `#,0.00`.
- **Display folders:**

  | Table | Folders |
  |---|---|
  | Fact Crashes | `Volume`, `Reported Casualties`, `Severity`, `Time Intelligence`, `Data Quality`, `Helpers` |
  | Fact Crash Persons | `Volume`, `Recorded Casualties`, `Demographics`, `Rates` |
  | Fact Crash Vehicles | `Volume`, `Occupancy`, `Vehicle & Driver` |

- **Descriptions.** A `///` line above each measure states three things:
  - **Source.** Reported injury counts or recorded injured persons. For example, the header total of
    deaths is 3,617 where person records give 3,636. The header total also misses 20 deaths on crashes
    where `Persons Killed` is NULL but the road-user parts are filled.
  - **Denominator.** Which rows the measure divides by, where relevant.
  - **2016 break.** The caveat on every person-level rate: before 2016, `Fact Crash Persons` holds only
    injured and killed people.
- **Glossary terms.** **Injury crash** (at least one reported injury) and **fatal crash** (at least one
  reported death) give the open term *Severity* a first definition. The occupancy measures settle the
  open term *Occupancy*. Both terms are recorded in `CONTEXT.md`.
- **Line → header filtering stays unsupported** (ADR-0005). That's why `Avg Vehicles per Crash` returns
  BLANK whenever `Dim Vehicle`, `Dim Driver` or `Dim Vehicle Circumstance` is cross-filtered.
- **The measure catalogue.** The DAX below came from the 2026-10-12 query-scoped prototype and encodes
  each decision exactly. Measures marked † were changed in review and run against Dev. (The one measure
  marked ‡, not run at drafting, was `Avg Vehicles per Crash`; ticket 03 ran it on 2026-10-12.)

  | Table | Measure | DAX |
  |---|---|---|
  | Fact Crashes | Total Crashes | `COUNTROWS('Fact Crashes')` |
  | Fact Crashes | First Data Date † (hidden) | `LOOKUPVALUE('Dim Date'[Date], 'Dim Date'[date_key], CALCULATE(MIN('Fact Crashes'[date_key]), REMOVEFILTERS()))` |
  | Fact Crashes | Last Data Date † (hidden) | `LOOKUPVALUE('Dim Date'[Date], 'Dim Date'[date_key], CALCULATE(MAX('Fact Crashes'[date_key]), REMOVEFILTERS()))` |
  | Fact Crashes | Total Persons Injured | `SUM('Fact Crashes'[Persons Injured])` |
  | Fact Crashes | Total Persons Killed | `SUM('Fact Crashes'[Persons Killed])` |
  | Fact Crashes | Total Pedestrians Injured | `SUM('Fact Crashes'[Pedestrians Injured])` |
  | Fact Crashes | Total Pedestrians Killed | `SUM('Fact Crashes'[Pedestrians Killed])` |
  | Fact Crashes | Total Cyclists Injured | `SUM('Fact Crashes'[Cyclists Injured])` |
  | Fact Crashes | Total Cyclists Killed | `SUM('Fact Crashes'[Cyclists Killed])` |
  | Fact Crashes | Total Motorists Injured | `SUM('Fact Crashes'[Motorists Injured])` |
  | Fact Crashes | Total Motorists Killed | `SUM('Fact Crashes'[Motorists Killed])` |
  | Fact Crashes | Injury Crashes | `CALCULATE([Total Crashes], 'Fact Crashes'[Persons Injured] > 0)` |
  | Fact Crashes | Fatal Crashes | `CALCULATE([Total Crashes], 'Fact Crashes'[Persons Killed] > 0)` |
  | Fact Crashes | Injury Crash Rate % | `DIVIDE([Injury Crashes], [Total Crashes])` |
  | Fact Crashes | Fatalities per 1,000 Crashes | `DIVIDE([Total Persons Killed], [Total Crashes]) * 1000` |
  | Fact Crashes | Vulnerable Road User Fatality % | `DIVIDE([Total Pedestrians Killed] + [Total Cyclists Killed], [Total Persons Killed])` |
  | Fact Crashes | Avg Daily Crashes † | `VAR f = [First Data Date] VAR l = [Last Data Date] RETURN DIVIDE([Total Crashes], COUNTROWS(FILTER(VALUES('Dim Date'[Date]), 'Dim Date'[Date] >= f && 'Dim Date'[Date] <= l)))` |
  | Fact Crashes | Crashes PY † | `VAR l = [Last Data Date] RETURN IF(MIN('Dim Date'[Date]) <= l, CALCULATE([Total Crashes], SAMEPERIODLASTYEAR(FILTER(VALUES('Dim Date'[Date]), 'Dim Date'[Date] <= l))))` |
  | Fact Crashes | Crashes YoY % † | `DIVIDE([Total Crashes] - [Crashes PY], [Crashes PY])` |
  | Fact Crashes | Crashes Rolling 12M † | `VAR l = [Last Data Date] RETURN IF(MIN('Dim Date'[Date]) <= l, CALCULATE([Total Crashes], DATESINPERIOD('Dim Date'[Date], MIN(MAX('Dim Date'[Date]), l), -12, MONTH)))` |
  | Fact Crashes | Geocoded Crash % † | `DIVIDE(CALCULATE([Total Crashes], 'Fact Crashes'[Latitude] <> 0), [Total Crashes])` |
  | Fact Crash Persons | Person Records | `COUNTROWS('Fact Crash Persons')` |
  | Fact Crash Persons | Persons Involved | `CALCULATE([Person Records], NOT 'Dim Person'[Person Role] IN {"Registrant","Witness","Owner","Notified Person","Policy Holder"})` |
  | Fact Crash Persons | Injured Persons (Person-Level) | `CALCULATE([Person Records], 'Fact Crash Persons'[Is Injured] = TRUE())` |
  | Fact Crash Persons | Killed Persons (Person-Level) | `CALCULATE([Person Records], 'Fact Crash Persons'[Is Killed] = TRUE())` |
  | Fact Crash Persons | Average Age | `AVERAGE('Fact Crash Persons'[Person Age])` |
  | Fact Crash Persons | Average Age of Killed | `CALCULATE([Average Age], 'Fact Crash Persons'[Is Killed] = TRUE())` |
  | Fact Crash Persons | Child Casualties (<18) † | `CALCULATE([Person Records], KEEPFILTERS(FILTER(ALL('Fact Crash Persons'[Person Age]), NOT ISBLANK('Fact Crash Persons'[Person Age]) && 'Fact Crash Persons'[Person Age] < 18)), KEEPFILTERS(FILTER(ALL('Fact Crash Persons'[Is Injured], 'Fact Crash Persons'[Is Killed]), 'Fact Crash Persons'[Is Injured] \|\| 'Fact Crash Persons'[Is Killed])))` |
  | Fact Crash Persons | Ejection Rate % † | `DIVIDE(CALCULATE([Person Records], 'Dim Person'[Ejection] IN {"Ejected","Partially Ejected"}), CALCULATE([Person Records], 'Dim Person'[Ejection] IN {"Ejected","Partially Ejected","Not Ejected","Trapped"}))` |
  | Fact Crash Persons | Person Fatality Rate % | `DIVIDE([Killed Persons (Person-Level)], [Persons Involved])` |
  | Fact Crash Vehicles | Vehicles Involved | `COUNTROWS('Fact Crash Vehicles')` |
  | Fact Crash Vehicles | Avg Vehicles per Crash † | `IF(ISCROSSFILTERED('Dim Vehicle') \|\| ISCROSSFILTERED('Dim Driver') \|\| ISCROSSFILTERED('Dim Vehicle Circumstance'), BLANK(), DIVIDE([Vehicles Involved], [Total Crashes]))` |
  | Fact Crash Vehicles | Total Occupants | `SUM('Fact Crash Vehicles'[Vehicle Occupants])` |
  | Fact Crash Vehicles | Vehicles with Occupant Data | `CALCULATE([Vehicles Involved], NOT ISBLANK('Fact Crash Vehicles'[Vehicle Occupants]))` |
  | Fact Crash Vehicles | Avg Occupants per Vehicle | `DIVIDE([Total Occupants], [Vehicles with Occupant Data])` |
  | Fact Crash Vehicles | Occupant Data Coverage % | `DIVIDE([Vehicles with Occupant Data], [Vehicles Involved])` |
  | Fact Crash Vehicles | Avg Vehicle Age at Crash | `AVERAGEX(FILTER('Fact Crash Vehicles', NOT ISBLANK(RELATED('Dim Vehicle'[Vehicle Model Year]))), RELATED('Dim Date'[Year]) - RELATED('Dim Vehicle'[Vehicle Model Year]))` |
  | Fact Crash Vehicles | Unlicensed Driver % † | `DIVIDE(CALCULATE([Vehicles Involved], 'Dim Driver'[Driver License Status] = "Unlicensed"), CALCULATE([Vehicles Involved], 'Dim Driver'[Driver License Status] IN {"Licensed","Unlicensed","Permit"}))` |

- **Literal filter values were verified in Dev on 2026-10-12.** Person Role includes `In-Line Skater` and

  vehicles) are excluded from both sides of `Unlicensed Driver %`. Standardising them is parked in

## Testing Decisions

- **One seam: DAX queries against the deployed semantic model in each stage** (`execute_dax_query`). It's
  the highest seam available and the one report authors consume. No new seam is introduced.
- **A good test checks external behaviour.** It evaluates the *model's* measure in a filter context and
  compares it with an **independent** expression in the same query: `COUNTROWS` or `SUM` over the raw
  column with explicit filters. It must not re-implement the measure's own DAX. Expected values are
  computed at run time, never hard-coded, because CDC runs move the counts.
- **What gets tested:**
  - **Base equality.** Each count or sum measure equals its independent expression by `Dim Date`[Year].
  - **Regression cases from the review.** These are the defects, re-asserted:
    - `Child Casualties (<18)` equals an independent count that excludes blank ages.
    - `Crashes Rolling 12M` and `Crashes PY` are BLANK for every year after `Last Data Date`.
    - `Crashes PY` for the last data year equals the prior year's crashes up to the same day.
    - `Ejection Rate %` and `Unlicensed Driver %` denominators equal counts of known statuses only.
    - `Avg Daily Crashes` under a single contributing-factor filter uses calendar days, not days with
      crashes.
  - **Guard.** `Avg Vehicles per Crash` returns BLANK when sliced by `Dim Vehicle`[Vehicle Type], and a
    value when sliced by `Dim Location`[Borough].
  - **Metadata.** `INFO.VIEW.MEASURES` lists 38 measures, 2 of them hidden, every one with a description,
    format string and display folder. `INFO.VIEW.COLUMNS` shows the 10 columns hidden.
  - **No regression.** `/dax-smoke-test` passes unchanged in each stage.
- **Prior art.** The CC skill `/dax-smoke-test` (self-scoring DAX with independent expected values). The
  2026-10-12 query-scoped `DEFINE MEASURE` prototype runs. The 2026-08-12 occupancy-denominator fix,
  which shows why a denominator is profiled before it is trusted.

## Out of Scope

- Standardising Driver License Status codes (`.scratch/_Doubtful/driver-license-status-codes/`).
- Calculation groups, field parameters, and further time intelligence (YTD, QTD, MoM).
- Age bands and other new columns or dimensions.
- Measures that filter line → header, such as crashes involving a pedestrian (ADR-0005,
  `.scratch/_Doubtful/line-to-header-filtering/`).
- Measures on Vehicle Type or Vehicle Make, which are uncleansed free text.
- Reports. They're authored in the Fabric web UI after this spec.
- RLS and OLS roles.

## Further Notes

- **2016 break.** Person-level rates and "involved" counts aren't comparable across 2016. Every such
  measure's description says so.
- **Bridge totals.** Totals sliced by contributing factor exceed the overall total by design, because
  each crash counts once under every factor it has.
- **Validation figures from the Dev prototype (2026-10-12):**
