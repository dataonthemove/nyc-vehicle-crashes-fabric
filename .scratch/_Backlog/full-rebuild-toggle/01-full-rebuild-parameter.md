A `full_rebuild` boolean on the Stage load pipeline would run the two DDL notebooks before Transform.\
(drop and recreate every Warehouse table)

## Why deferred

- If a scheduled run carried `true`, it would wipe the Warehouse, and Direct Lake would serve empty tables until the reload finished.
- The manual path already works: run both DDL notebooks, then trigger the Stage load.
- It is unverified whether a pipeline Notebook activity can execute T-SQL-kernel notebooks.

If it is picked up, prefer a separate manually triggered rebuild pipeline over a parameter on the scheduled one.
